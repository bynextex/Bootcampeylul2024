46-day web development training curriculum repository covering HTML5, CSS3, modern JavaScript, and jQuery through daily code drills and hands-on exercises.

## Curriculum Breakdown

| Days | Focus | Covered Topics |
|---|---|---|
| 01 - 05 | HTML Fundamentals | Document structure, text elements, tables, forms, attributes |
| 06 - 09 | CSS Fundamentals | Selectors, box model, floats, backgrounds, typography |
| 10 - 15 | Layouts & Positioning | CSS Grid, Flexbox, transitions, positioning contexts |
| 16 - 19 | Core JavaScript | Variables, data types, operators, conditionals |
| 20 - 25 | DOM & Functions | Functions, objects, arrays, loops, DOM selection and mutation |
| 26 - 30 | Advanced JavaScript | Events, JSON handling, callbacks, higher-order functions |
| 31 - 35 | Web APIs | Fetch API, Canvas API, Speech synthesis, async logic |
| 36 - 39 | Projects | Dino runner game iterations, real-time clock, canvas effects |
| 40 - 46 | jQuery & UI Tools | jQuery integration, dynamic color pickers, responsive exercises |

## Key Exercises

- Digital Clock (Day 20): Real-time interval-driven clock display
- Dino Runner (Days 37-39): Canvas-based jumping runner game iterations
- Color Tool (Days 42-43): Palette generation and RGB/HEX conversion tool
- Weather Client (Day 34): Async weather fetch and DOM renderer
