A comprehensive 46-day web development bootcamp journey covering HTML, CSS, JavaScript, jQuery, and more. Each day's exercises and projects are organized in separate folders.

---

## 📖 Curriculum

| Days | Topic | Key Concepts |
|------|-------|-------------|
| 01–05 | **HTML Fundamentals** | Page structure, lists, tables, forms, links, favicon |
| 06–09 | **CSS Basics** | Selectors, box model, float layout, gradients, pseudo-elements |
| 10–15 | **CSS Advanced** | Fonts, positioning, Flexbox, CSS Grid, transitions |
| 16–19 | **JavaScript Intro** | Variables, operators, data types, increment/decrement |
| 20–25 | **JavaScript DOM** | Functions, objects, arrays, loops, DOM manipulation |
| 26–30 | **JS Advanced** | Events, JSON, callbacks, array methods, animations |
| 31–35 | **Async & APIs** | Fetch API, Speech API, Canvas, more array methods |
| 36–39 | **Mini Projects** | Clock app, Dino game (3 iterations), loading animations |
| 40–46 | **jQuery & Beyond** | jQuery basics, color picker app, final projects |

## 🎮 Notable Projects

- **⏰ Digital Clock** (Day 20) — Real-time clock with custom styling
- **🦕 Dino Game** (Days 37–39) — Browser-based game with progressive improvements
- **🎨 Color Picker** (Days 42–43) — Interactive color selector with TR/EN language support
- **🌤️ Weather App** (Day 34) — Fetch API-based weather display

1. Clone the repo: `git clone https://github.com/bynextex/Bootcampeylul2024.git`

3. Follow along with the exercises
